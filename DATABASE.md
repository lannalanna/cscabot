# База данных пользователей и прогресса

## Описание

Бот использует SQLite для хранения информации о пользователях, их ответах и прогрессе по темам.

## Структура базы данных

### Таблица `users`
- `id` (INTEGER, PK) - Telegram user ID
- `username` (TEXT) - имя пользователя
- `language_code` (TEXT) - код языка
- `source` (TEXT) - источник/вариант старта (например, "stepik", "invite" или NULL)
- `invited_by` (TEXT) - сырой payload из команды /start
- `created_at` (TEXT) - дата первого визита (ISO 8601)
- `updated_at` (TEXT) - дата последнего обновления (ISO 8601)

### Таблица `answers`
- `id` (INTEGER, PK, AUTOINCREMENT) - уникальный ID ответа
- `user_id` (INTEGER, FK) - ID пользователя
- `topic` (TEXT) - название темы
- `question_index` (INTEGER) - индекс вопроса (j)
- `chosen_index` (INTEGER) - выбранный вариант ответа (0-4)
- `correct` (INTEGER) - правильность ответа (0 или 1)
- `created_at` (TEXT) - дата ответа (ISO 8601)

### Таблица `progress`
- `user_id` (INTEGER, FK) - ID пользователя
- `topic` (TEXT) - название темы
- `last_question_index` (INTEGER) - следующий вопрос для показа
- `total_answered` (INTEGER) - всего ответов по теме
- `total_correct` (INTEGER) - всего правильных ответов по теме
- `updated_at` (TEXT) - дата последнего обновления
- PRIMARY KEY: (user_id, topic)

## Расположение файла БД

По умолчанию база данных находится в `data/bot.db` (относительно корня проекта).

Путь можно переопределить через переменную окружения:
```bash
export BOT_DB_PATH=/path/to/custom/bot.db
```

## Использование

### Инициализация
База данных автоматически создаётся при первом запуске бота. Таблицы создаются автоматически, если их нет.

### Команды бота

- `/start` - регистрирует/обновляет пользователя в БД
- `/stats` - показывает статистику пользователя (всего ответов, правильных, по темам)

### Прогресс

При ответе на вопрос автоматически:
1. Сохраняется ответ в таблицу `answers`
2. Обновляется прогресс в таблице `progress`

В главном меню отображается кнопка "Продолжить" для тем, где есть незавершённый прогресс.

## Миграция старых данных

Старые логи из `usr.txt` и `res.txt` продолжают записываться для обратной совместимости, но основная работа ведётся через БД.

Для импорта старых данных можно написать отдельный скрипт, который:
1. Парсит `usr.txt` и создаёт записи в таблице `users`
2. Парсит `res.txt` и создаёт записи в таблице `answers` и обновляет `progress`

## Резервное копирование

Рекомендуется регулярно делать резервные копии файла `data/bot.db`:

```bash
cp data/bot.db data/bot.db.backup
```

Или использовать SQLite команды:
```bash
sqlite3 data/bot.db ".backup data/bot.db.backup"
```
