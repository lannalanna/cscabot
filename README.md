# CSCA Math Bot

Telegram-бот для обучения математике, разработанный для подготовки к экзаменам CSCA. Бот предоставляет интерактивные вопросы по различным математическим темам на английском и китайском языках.

## 📋 Описание

CSCA Math Bot — это образовательный Telegram-бот, который помогает студентам готовиться к математическим экзаменам. Бот предлагает вопросы с множественным выбором по различным темам математики, включая тригонометрию, множества, физику, геометрию и другие разделы.

### Основные возможности

- 🎯 Интерактивные вопросы с множественным выбором
- 📚 Множество тем для изучения
- 🌐 Поддержка английского и китайского языков
- 🖼️ Поддержка изображений в задачах
- 💡 Картинки-подсказки по задачам из `data/images/hints` (зависят от языка интерфейса ru/en)
- 📹 Ссылки на видео-разборы задач
- 📊 Логирование активности пользователей
- 🔗 Интеграция с Telegram-каналом для обсуждения задач
- 🎁 Система приглашений для бесплатного использования
- 🤖 Ответы на вопросы пользователя с помощью LLM (в контексте подготовки к CSCA)
- 🧠 Подробное объяснение решения задачи с помощью LLM по кнопке «Объяснить подробнее»

## 🚀 Установка и запуск

### Требования

- Python 3.7 или выше
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка

1. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram
2. Откройте файл `testbot.py` и замените значение `API_TOKEN` на ваш токен:

```python
API_TOKEN = 'ВАШ_ТОКЕН_БОТА'
```

3. Убедитесь, что структура директорий соответствует ожидаемой:
   - `/data/` — директория для данных (в продакшене)
   - `/data/images/` — изображения к условиям задач
   - `/data/images/hints/` — картинки-подсказки (см. раздел ниже)
   - Файлы данных: `data.txt`, `data_jan.txt`, `data_physics.txt`
   - Файлы логов: `usr.txt`, `res.txt`

### Запуск бота

```bash
python testbot.py
```

## 💡 Картинки-подсказки (`data/images/hints`)

В меню задачи может быть кнопка подсказки: бот ищет файл в каталоге **`data/images/hints`** (рядом с `data.txt`, путь задаётся через `DATA_DIR`).

**Условия:**

- У задачи в данных должно быть поле **`id`** (строка, например `RI10`).
- Файл подсказки именуется так: **`<id><язык>.<расширение>`**, где язык — **`ru`** или **`en`** в зависимости от языка интерфейса пользователя (не `ru` → используется `en`).
- Расширения: `.png`, `.jpg`, `.jpeg`, `.webp` (или файл без расширения, если так заведено).

**Дополнительно:** если для полного `id` файла нет, бот пробует префикс подтемы (буквенный префикс `id`, например для `RI10` — `RI`), чтобы можно было одной картинкой покрыть группу задач.

Примеры имён: `RI10ru.png`, `RI10en.png`, `RIru.png`.

## 🎓 Поддерживаемые темы

Бот поддерживает следующие математические темы:

- **Sets** (Множества)
- **Trigonometry** (Тригонометрия)
- **Physics** (Физика)

- **Hyperbola** (Гипербола)
- **Functions** (Функции)
- **Geometry** (Геометрия)
- **Sequences** (Последовательности)

- **Logarithmic Functions** (Логарифмические функции)
- **Complex Numbers** (Комплексные числа)
- **Probability** (Вероятность)

## 📝 Формат данных вопросов

Вопросы хранятся в JSON формате со следующей структурой:

```json
{
    "chinese": "问题文本（中文）",
    "english": "Question text in English",
    "options": ["A. Option 1", "B. Option 2", "C. Option 3", "D. Option 4"],
    "answer": "B",
    "topic": "sets",
    "type": "dec",
    "n": 1,
    "link": "https://t.me/c/3305923058/19",
    "img": "image_filename.png"
}
```

### Поля:

- `chinese` — текст вопроса на китайском языке
- `english` — текст вопроса на английском языке
- `options` — массив вариантов ответов
- `answer` — правильный ответ (A, B, C, D или E)
- `topic` — тема вопроса
- `type` — тип вопроса (опционально)
- `n` — номер вопроса (опционально)
- `link` — ссылка на видео-разбор (опционально)
- `img` — имя файла изображения условия в `data/images/` (опционально)
- `id` — идентификатор задачи; нужен для привязки файла подсказки в `data/images/hints/` (опционально)
- `long` — длинные варианты ответов (генерируется автоматически)

## 🔧 Основные функции

### Обработчики команд

- `/start` — запуск бота и отображение меню выбора темы

### Callback-обработчики

- `qst_{topic}_{index}_{answer}` — обработка ответа пользователя
- `next_{topic}_{index}` — переход к следующему вопросу
- `explain_{topic}_{index}` — получение ссылки на видео-разбор

### Вспомогательные функции

- `log(usr, lg=[])` — логирование действий пользователя
- `makeinvite(usr)` — генерация персональной ссылки-приглашения
- `start_kb()` — создание клавиатуры выбора темы
- `inline_kb(top, j, showvideo)` — создание клавиатуры с вариантами ответов
- `inline_kb_next(top, j)` — создание клавиатуры "Следующий вопрос"
- `inline_kb_explain(top, j, k)` — создание клавиатуры после объяснения

## 📊 Логирование

Бот ведет логи в следующих файлах:

- `/data/usr.txt` — логи регистрации пользователей (формат: дата, ID, username, команда)
- `/data/res.txt` — логи ответов и действий пользователей (формат: дата, ID, username, действие, тема, индекс вопроса, ответ, результат)

## ⚙️ Особенности реализации

1. **Обработка длинных вариантов ответов**: Если вариант ответа длиннее 45 символов, он выносится в отдельное поле `long`, а в `options` остаются только метки A, B, C, D.

2. **Система приглашений**: После 7-го вопроса пользователю предлагается поделиться персональной ссылкой-приглашением для продолжения использования бота.

3. **Специальные пользователи**: Для пользователей из списка `stepik` и пользователя `evangecalista` скрываются ссылки на видео.

4. **Проверка подписки**: При первом вопросе проверяется статус подписки пользователя на канал `@csca_math_exam`.

## 🔒 Безопасность

⚠️ **Важно**: В текущей версии токен бота хранится в открытом виде в коде. Для продакшена рекомендуется:

1. Использовать переменные окружения для хранения токена
2. Добавить файл `.env` в `.gitignore`
3. Использовать библиотеку `python-dotenv` для загрузки переменных окружения

Пример:

```python
import os
from dotenv import load_dotenv

load_dotenv()
API_TOKEN = os.getenv('BOT_TOKEN')
```

## 🤝 Вклад в проект

Для добавления новых вопросов:

1. Откройте соответствующий JSON файл или `data.txt`
2. Добавьте новый объект вопроса в формате, описанном выше
3. Убедитесь, что поле `topic` соответствует одной из поддерживаемых тем
4. Для вопросов с картинкой условия поместите файл в `data/images/` и укажите имя в поле `img`
5. Для картинки-подсказки добавьте `id` в задачу и положите файлы в `data/images/hints/` по правилам из раздела выше
